# Gaming Industry Data Mining Project

## Overview
This project demonstrates the complete data mining lifecycle using a gaming industry dataset. The project includes data preprocessing, exploratory data analysis, classification, clustering, association rule mining, and visualization.

---

## Objectives
- Perform data preprocessing and cleaning
- Implement classification algorithms
- Apply clustering techniques
- Generate association rules
- Analyze gaming industry trends

---

## Technologies Used
- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Mlxtend
- Jupyter Notebook

---

## Dataset
Dataset contains information related to gaming industry trends including:
- Revenue
- Player count
- Peak concurrent players
- Metacritic score
- Release year

Dataset size: 1000+ records

---

## Algorithms Implemented

### Classification
- Decision Tree
- Random Forest

### Clustering
- K-Means Clustering

### Association Rule Mining
- Apriori Algorithm

---

## Evaluation Metrics
- Accuracy
- Cross Validation
- Silhouette Score
- Feature Importance

---

## Results
- Best Classifier: Random Forest
- Best Clusters: k=2
- Silhouette Score: 0.230

---
